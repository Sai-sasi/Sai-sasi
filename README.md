## Research Background

🧠 **MSc Dissertation — University of Glasgow (BBSRC Funded)**  
*Electrophysiological Characterisation of Calbindin- and Phox2a-Lineage Spinal Neurons in Response to Somatosensory Stimuli*

- Performed whole-cell patch-clamp recordings from lamina I spinal projection neurons in ex vivo mouse spinal cord
- Characterised cold-selective EPSC responses in Calb1-expressing neurons vs broader Phox2a lineage
- Found significantly greater cold selectivity in Calb-Cre population (Fisher's exact test, **p = 0.033**)
- Supports labelled-line model of cold pain encoding in the dorsal horn
- Data analysed in Clampfit, R Studio; code available in this repository

🧬 **fiji/Image J analysis**
